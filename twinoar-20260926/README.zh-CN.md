# TWINOAR 🛶（双桨）

两只桨、一条河。一分钟一局的独木舟街机游戏——按住屏幕**左半边**划左桨，**右半边**划右桨。操作就这么多，活着才是本事。

**▶ 在线试玩：https://xiangjianan.github.io/daily-games/twinoar-20260926//**

## 玩法

- **按住左半屏** → 左桨划水 → 船头向**右**转
- **按住右半屏** → 右桨划水 → 船头向**左**转
- **双手齐按** → 直行 + 水流**加速（BOOST）**。距离就是分数，想上榜只能赌加速……而加速也是撞石头的最快方式。
- 躲开礁石，穿过越来越窄的河道，小心会扭偏船头的漩涡，连吃金币叠 combo（最高 ×5）。
- 碰到礁石即翻船。点一下，一秒内重新出发。

桌面端：**鼠标左键** = 左桨，**右键** = 右桨（也支持 A/D 键）。

## 为什么停不下来

- **3 秒上手**：就两个按住动作，剩下交给船。「左桨却让船右转」的不对称性就是全部技巧曲线。
- **一个动词里的风险旋钮**：加速=「双手齐按」，贪心只是一个拇指的决定——随时可用，随时致命。
- **不断恶化的河**：水流 130→330 px/s 逐步拉满，安全航道 190→110 px 持续收窄，25 秒后漩涡入场开始扭你的船头。前 30 秒是馈赠，第二分钟是刀口舔血。
- **combo 诱饵**：金币排在航道正中——恰好是安全线所在，于是贪心线和保命线重合了……直到礁石表示不同意。
- **亚秒重开**：翻船 → 点一下 → 继续划。没有菜单、没有加载、没有怜悯。

## 技术

单文件 `index.html`，Canvas 2D，原生 JS，零依赖，离线可玩。音效由 WebAudio 实时合成（无音频文件）。最高分存 `localStorage`。

## 设计笔记

操作手感借了真实独木舟的物理直觉——桨划一侧、船头摆向另一边——并把它做成双拇指协调游戏。所有机制都喂给同一个张力：速度即分数，转向即生存，而同样两只拇指必须同时干好这两件事。
