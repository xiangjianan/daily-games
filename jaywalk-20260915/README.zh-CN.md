# JAYWALK（乱穿马路）

*看清间隙，冲过车流。* —— 单拇指车流间隙判断街机。

**▶ 在线试玩：https://xiangjianan.github.io/daily-games/jaywalk-20260915//**

## 玩法说明

- 小人们在路边排队，四条车道车流滚滚。
- **点击屏幕左 / 中 / 右三分之一**，派出队首小人沿该列冲上马路。
- 一个小人穿过四条车道约需 2.5 秒——读好车间隙，注意路口边缘的**车灯预警**（有车即将入场时会提前闪烁）。
- 1.6 秒内连续送人过线可叠加连击倍率（最高 ×5），超时归零。
- 贴身擦过汽车有 **+5 CLOSE!** 奖励。贪婪就是策略——同时派更多人、追着擦车拿奖励、连击一波带走。
- 碰撞一次即结束，点一下立刻重开。

25 秒后卡车入场，车流密度和车速持续爬升。你能送多少人过街？

## 沉迷机制设计笔记

| 心理钩子 | 参考来源 | JAYWALK 的用法 |
|---|---|---|
| 3 秒上手 | Frogger（1981）、Crossy Road | 唯一操作：点屏幕三分之一。没有教学，只有精通。 |
| 读间隙的张力 | Frogger 的车道间隙 | 刷车有预警，每次派遣都是一次"看得见摸得着"的公平赌注——死得服气，才想再来。 |
| 贪婪 vs 安全 | 车流指挥类游戏 | 得分随**同时过街人数**和擦车次数放大，"安全打法"和"得分打法"是两套打法。 |
| 连击雪球 | Crossy Road 的连跳 | 1.6 秒连击窗口奖励爆发式决策，可见的倒计时条不断追问"还能再塞一个吗？" |
| 秒级重开 | Flappy Bird | 死亡 → 点击 → 新一局。你和报复之间没有菜单。 |

单文件 HTML5 + Canvas + WebAudio 合成音效。零构建、零依赖、无需联网。鼠标与触屏均可。

## 本地运行

浏览器直接打开 `index.html`，或：

```bash
python3 -m http.server 8000
# http://localhost:8000
```

最高分与最高连击保存在 `localStorage`。
