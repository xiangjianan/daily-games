# Paint Rush 涂色冲刺 · 第 21 期

**Paint Rush**——你的手指就是滚筒刷，限时把白墙刷到目标覆盖率，刷完即刻过关。

## 玩法说明

- **按住拖动**即可刷漆：滚筒 1:1 跟随手指，刷过的瓦片染成青色。
- 每局 **40 秒**，时间到时覆盖率须达标：**首关 55%，逐关 +7%**（封顶 94%）。
- 🖤 **黑刷对手**（第 2 关起）在墙上游走，会把你的青漆重新涂黑——实时抢占地皮，与其东摸一笔西补一下，不如整片 finishing。
- 🟥 **红漆禁区**（第 3 关起）刷到直接 **-6 秒**。
- 🟨 **金漆瓦片** +1.2 秒，留给眼尖的人。
- 没达标？点一下立刻重刷本关（重开 <1 秒）；达标自动进入下一关。

## 沉迷机制设计意图

- **3 秒上手**：拖动 = 刷漆，没有教程可写因为没有东西可学。
- **可见进度引擎**：覆盖率条实时爬向标线，铃响时"就差一点"的落差就是全部钩子（参考 Block Blast! 一系休闲爆款的连击 juice 与 HN 2024-25 成瘾设计报道）。
- **损失厌恶 vs 贪婪**：你优化路线的同时黑刷在吃掉你的成果——每一秒犹豫都有代价，每一笔大胆都有回报。
- **即时重开**：秒级重试保住"再来一局"回路不断裂；最高关卡存 localStorage 供攀比。

## 操作方式

- 鼠标：按住拖动。触屏：按住拖动。没有其他按键。

## 技术

单文件 HTML5 Canvas + 原生 JS，零依赖零构建，WebAudio 实时合成音效（无音频文件），离线可玩。
