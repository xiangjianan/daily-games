# 连锁瓜田 Fuse Farm 🍉💣

一键连锁爆炸街机小游戏：点炸弹瓜点燃引信，被波及的炸弹瓜会跟着炸，每连锁一层倍率翻倍，守住瓜田里三颗西瓜不被虫子啃光。

**在线试玩：** https://xiangjianan.github.io/daily-games/fuse-farm-20260928//

## 玩法

- 虫子从顶部爬进来，直奔三颗西瓜。一颗瓜被啃 3 口就没了；3 颗瓜全部沦陷，瓜田就守不住了。
- **点按任意炸弹瓜**引燃引信，闪烁 0.55 秒后爆炸，爆炸半径 95px。
- 半径内的虫子全部炸飞；半径内的**其他炸弹瓜会被连锁引爆**，每连锁一层分数倍率翻倍（×2、×4、×8…）。
- 炸弹是稀缺资源（场上最多 3 颗，缓慢再生），真正的技术是**耐心**：等虫子在炸弹边上聚成一团再点火，但别等到瓜被啃了才后悔——在虫子下嘴的瞬间把它炸掉，是这游戏里最解气的操作。

## 沉迷机制设计（设计笔记）

- **3 秒上手**：一个动词（点）、一个资源（炸弹）、一个威胁（虫），不需要教程。
- **贪婪循环**：多等一秒虫聚得更密、潜在连锁更高，但丢瓜的风险也更大——游戏把「再等一秒」做成了核心张力。
- **连锁奖赏**：三连以上的连锁触发慢动作 + 屏震 + 粒子爆裂，×8 连锁炸开的瞬间就是全部爽点，借鉴了 Block Blast! 这类爆款的连击 juice。
- **失败即重开**：单局一分钟内结束，死亡一键重开零摩擦，最高分存 localStorage——与《羊了个羊》同一套心理回路。
- **难度爬坡 + 随机性**：虫速和刷新随时间加压，随机游走的路径让每团虫聚法都不同，只能读场不能背版。

## 操作

- 点 / 点击炸弹瓜。没了。鼠标和触屏都支持。

## 技术

- 单文件 HTML5 Canvas，零依赖、零构建、离线可玩，音效由 WebAudio 实时合成（无音频文件）。
