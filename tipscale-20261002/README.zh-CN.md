# 不倒天平 Tipscale — 每日沉迷小游戏 #24

一款单键物理配平游戏。积木不断进入队列，你点按秤杆上方的任意位置，把队首积木投到那里。每块积木都带来力矩，秤杆实时倾斜——超过 16° 外侧积木开始打滑外漂，超过 30° 秤杆折断。一局就是一座注定倾覆的天平，看你能让它平衡多久。

**试玩：** https://xiangjianan.github.io/daily-games/tipscale-20261002/

## 玩法

- **点按/点击**水平位置——队首积木从天而降，落在秤杆的那个点上。
- 每块积木标有**重量**（和宽度）：又重又宽的块分高，但扭矩也大。
- **左右交替投放**积攒 COMBO（分数乘数最高约 ×3）。
- **★ 金块**得分 ×5——但重量 ×1.9。贪不贪，是一道力矩题。
- 约 15 秒后开始刮**风阵**（黄色箭头提前约 1 秒预警方向），会把秤杆往一边推。
- 任意积木滑出杆端，或倾角超过 33° 持续 0.6 秒折断——游戏结束。

## 沉迷机制设计意图

- **可见且诚实的物理**：倾角表盘 + 持续倾斜的秤杆给出连续可读的危险信号，每次死亡都能归因到「上一块投哪了」，于是「再来一局」无法拒绝。
- **一个动词压三个旋钮**：投放位置同时决定得分、连击和风险（金块、远端极限位）。
- **死前先打滑**：超过 16° 积木带摩擦外漂，但配平后还能滑回来——濒死挽回制造最强的松弛→重开循环。
- **短核心循环**：单局 30–120 秒，一键重开，最高分存 localStorage。
