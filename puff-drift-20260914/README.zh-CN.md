# PUFF 🎈（气球漂流）

*按住充气变大上浮，松开漏气变小下沉——一个键，同时控制你的「体型」和「高度」。*

**[▶ 浏览器直接玩](https://xiangjianan.github.io/daily-games/puff-drift-20260914//)** — 单个 HTML 文件，零依赖，支持鼠标、触屏、空格键。

## 玩法说明

- **按住**（鼠标 / 触屏 / 空格）：气球充气——体积变大，同时受浮力上升。
- **松开**：气球漏气——体积变小，同时下沉。
- 钻过石柱之间的缝隙。碰到粉色尖刺或石柱，气球爆掉。
- **◆ 小颗青色宝石**：只有体型**小**的时候才能吃到（要收它就得泄气）。
- **⬢ 大颗金色宝石**：只有体型**大**的时候才能吃到（要收它就得充气）。
- 3.5 秒内连续吃到匹配宝石可叠 **连击倍率**（最高 ×3）。
- 分数 = 距离 + 宝石。飘得越远，尖刺开始出现、缝隙越窄、卷轴越快。

## 为什么停不下来（设计笔记）

PUFF 借鉴了三个被验证过的心理钩子，但玩法内核是原创的：

1. **Flappy Bird 式重开循环**（[2014 年刷屏全球的那只鸟](https://en.wikipedia.org/wiki/Flappy_Bird)）——死亡零成本：点一下，半秒内重新起飞。大脑会把「再来一局」当成免费的。
2. **反转的大鱼吃小鱼**——不是《大鱼吃小鱼》那种「越大越好」的体型阶梯，这里的体型是一个**生存旋钮**：每一点体积都是用「过缝空间」换来的升力和吃宝石资格。贪婪第一次有了物理形状。
3. **一键双轴耦合**——向 [HN 上的 one-button game 设计讨论](https://hn.algolia.com/api/v1/search?query=%22one%20button%22%20game) 致意。按下不等于「跳」：它是一根同时推动两个轴的杠杆（更大 + 更高）。高手不是在躲关卡，而是跟着关卡一起**呼吸**。

再加标配：3 秒上手、单局 30–90 秒、每个动作都有合成音效反馈、挤压拉伸动画、屏震，以及随时可追的本地最高分。

## 技术

- 单个 `index.html`，原生 JS + Canvas，WebAudio 合成音效（无音频文件），localStorage 最高分。
- 无构建、无需联网，树莓派 Chromium 上稳 60fps。

## 本地运行

浏览器直接打开 `index.html`，或者：

```bash
python3 -m http.server 8080   # 然后访问 http://localhost:8080
```
