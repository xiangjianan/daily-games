# LIGHTKEEP（守灯人）

你就是灯塔。拖动光束扫过夜海，让光照在驶过的船上把它们的灯照满——但千万别让光停在克拉肯海怪身上。

## 玩法
- **拖动**屏幕任意位置（鼠标/触屏均可）——光束会朝手指方向转，但转速有上限，横扫一片海需要真实的时间成本。
- **船**从左侧漂来，右缘是暗礁。把光压在船上约 1.1 秒照满它的灯，满灯的船安全回家（+100 × 连击）。
- **连击**：6 秒内连续照满可叠倍率，最高 ×5。
- **黑船**漂到暗礁即沉没，扣一颗心。
- **海怪**约 20 秒后现身。光束照着它时红色怒气环会涨满——涨满即被触手夺心。扫过一下只会惊扰它，停下来照才是致命的。
- 3 心耗尽海面熄灭，点击立刻重燃。

## 设计笔记（心理钩子）
- **一个动词、两面刃**：救船的光也会激怒海怪——每一秒光照都是一次小赌注，风险旋钮内建在你唯一的操作里。
- **亚秒重开**：死亡后一秒内回到海面，两局之间只有 localStorage 里的最高分。
- **可见的险情**：灯笼充能条与海怪怒气环常驻可见，输了只会觉得「这一扫慢了」，而不是游戏藏了信息。
- **不加新规则的压力升级**：船更快更密、海怪更频繁——深度来自同一个 3 秒上手的核心循环上的持续加压。

## 技术
单文件 `index.html`——Canvas + 原生 JS，零构建、零依赖、离线可玩；WebAudio 合成音效，支持触屏与鼠标。
