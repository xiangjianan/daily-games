# 星轨跳站 Orbita — 引力跳站街机

一键操作的太空甩出街机游戏：把小飞船从一条轨道甩到下一条轨道。单文件 HTML5 demo——零构建、零依赖、离线可玩。

**试玩：** https://xiangjianan.github.io/daily-games/orbit-hop-20261001/

## 玩法

- 飞船自动绕当前行星匀速公转。
- **点按 / 点击 / 空格**释放：飞船沿切线方向飞出（黄色虚线预瞄线精确显示飞行路径）。
- 飞进下一颗行星的捕获圈即被捕获进入新轨道，每次捕获得 **10 × 连击** 分。
- 2.5 秒内连续转轨可把连击叠到 **×5**。
- 撞上行星本体、飞出屏幕、或在同一颗行星上滞留过久（4 秒后行星**过载塌缩**——捕获圈会先闪黄再闪红警告），本局结束。
- 一条命，秒开下一局。

## 难度爬坡

- 捕获圈随时间收窄（110 → 70 px）。
- 行星间距拉大（300 → 560 px），切线对准窗口越来越稀有。
- 40 秒后出现红刺行星（圈更小）；55 秒后部分行星带碎石环。

## 沉迷机制设计意图

- **3 秒上手**：只有一个动词（点按），唯一的瞄准辅助（虚线切线）直接把数学做了。
- **核心张力**：等完美的切线对准 vs 4 秒塌缩倒计时——犹豫会死，慌张甩出会偏。每次死都怪自己的时机。
- **Near-miss 引擎**：看着虚线差一个身位擦过捕获圈，是「再来一局」的最强触发器。
- **连击扶梯**：快速连续跳站享 ×5 倍率，鼓励冒险快节奏而非苟着（塌缩计时也把苟这条路堵死了）。
- **零摩擦重开**：死亡 → 350ms 防误触 → 点按 → 新局，全程不到一秒。

## 操作

- 点按屏幕任意位置，或空格 / 方向键上。
- 鼠标与多点触屏均支持，竖屏布局适配手机。

## 技术

单 `index.html`（约 290 行）：Canvas 2D、原生 JS、WebAudio 合成音效（无音频文件）、`localStorage` 最高分。内置 `?autotest` 机器人模式用于无头自检。
