# INKFALL（墨渊接珠）

用手指在棋盘上拖出会褪色的墨线坡道，把天而降的宝石引进左右滑动的黄金承接盆——并让炸弹**远离**它。单命制，一次一条线。

**在线试玩：https://xiangjianan.github.io/daily-games/inkfall-20260916//**

## 玩法

- **按住拖动**即可画墨线坡道。线条会发光，约 3.6 秒后褪色消失。
- **宝石（青色）**每颗 +10 分，引进盆里就安全；宝石落地直接终结本局。
- **炸弹（红色）必须拆弹**：引它在地面炸掉（落在盆附近 +5 分）；碰到承接盆就爆炸，游戏结束。
- 2.5 秒内连续接住可叠**连击**，最高 ×5 倍。
- 墨量是唯一资源：每条线都消耗墨量表，短暂延迟后回墨。线越长耗墨越多。
- 承接盆有**磁吸**——宝石落在盆附近会被轻轻吸进去，近失也算数。局时越长，帮助越少。

## 为什么停不下来

- **3 秒上手**：拖动即画，这就是全部教程。
- **单局 30–90 秒**：刷落速度、盆移速度、炸弹概率随时间爬坡。
- **创造感**：不同于纯反应类游戏，物理是你自己画的——每一局都是一台你亲手绘制的「戈德堡机械」（这是 *Happy Glass*、*Brain Dots* 等画线物理爆款的心理钩子，这里压缩进无尽街机循环）。
- **一条对称规则、相反目标**：宝石要进盆，炸弹要避开。同一套画线手艺镜像使用，大脑被迫来回切换模式。
- **墨量张力**：你永远比手里墨量多想要一条坡道。
- **秒开重开**：死亡到新局只需轻点一下。

## 操作

- 鼠标：按住拖动画线。
- 触屏：手指拖动画线。
- 点按开始 / 重开。最高分与最高连击保存在本地。

## 技术

单文件 HTML5 + Canvas + 原生 JS，零依赖、零构建、离线可玩。音效由 WebAudio 实时合成（无音频文件）。双击 `index.html` 即玩。
