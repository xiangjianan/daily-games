## 🎮 玩法

你的核心有正负两极：

- **按住 = 正极 ⊕，松开 = 负极 ⊖**（整个世界的色调随你翻转）
- 电荷从右侧源源不断飞来
- **同极** → 吞掉得分，连击雪球（每颗 = 100 × 当前连击，每 10 连击额外奖励）
- **异极** → 触碰即死
- **漏掉**（飞过没接到）→ 连击清零——**每一颗都必须接对**
- 吞噬积攒「超载条」，攒满触发 **6 秒 ×2 超载**（金色狂潮）

规则一句话：这不是躲弹幕，是把「翻转时机」打出节奏。

## 🧠 沉迷机制设计意图（今日调研 → 借鉴）

| 调研对象 | 借鉴的钩子 | 本作的原创组合 |
|---|---|---|
| [Hopera（HN 2026-09-11，节奏音游）](https://news.ycombinator.com/item?id=49660111) | 节奏流：操作本身就是音乐 | 连续同极波次 = 乐句，翻转点 = 节拍；吞噬音高随连击沿半音阶上行（经典多巴胺阶梯） |
| Ikaruga / Color Switch 一脉的极性机制 | 单键状态匹配的预判张力 | 「同一颗电荷因你的极性而在得分/死亡间切换」，且用「按住/松开」而非点击切换，翻转手感更像充能 |
| Flappy Bird | 死亡即 0.5s 重开、单局 30-120s | 死亡慢镜 0.9s + 任意点按重开，重开成本 < 1 秒 |
| 合成大西瓜 / 羊了个羊 | 即时反馈 + 可晒的成长数字 | 连击王、超载 ×2 金色时刻、死亡结算页「吞噬 N 颗 · 存活 N s」攀比 |

**原创度声明**：极性匹配的「状态」玩法有先例，但「按住/松开=充能式双态 + 全部弹道必接 + 漏接断连击 + 超载 ×2」的核心循环为本作原创组合，非现有游戏换皮。

## 🕹️ 操作

- **鼠标**：按住左键 = 正极，松开 = 负极
- **手机**：按住屏幕 / 松开
- **键盘**：空格键同上
- 死亡后点按任意处 0.5 秒重开

## 📈 难度曲线（数值设计）

- 电荷速度：`v(t) = min(380, 190 + 8·t^0.85)` → 初期飞行 1.9s（读盘充裕），60s 后 0.93s
- 出怪间隔：`max(0.38, 1.05 − 0.012t)` 秒，前 5 颗固定 1.15s 且正负交替（8 秒教学关）
- 波次：每 9-13s 一波，30s 前同极连发为主 → 30-60s 混色 → 60s+ 交替连打 + **闪电池**（中途变极，0.55s 白圈预告）
- 预期：前 30 秒稳赢建立信心，70-120s 进入手抖死亡区；单局 30 秒-2 分钟
