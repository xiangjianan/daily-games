# JINX（双子咒）

**两个世界，一颗按钮。** 每次点按同时让两个小人起跳——上面世界的琥珀色小人，和下面世界的青色小人。两边的尖刺都要跳过去，但头顶有垂晶时**绝不能跳**。

在线试玩：**https://xiangjianan.github.io/daily-games/jinx-20260924//** —— 双击 `index.html` 也能玩，零依赖，完全离线。

## 玩法

- 点屏幕任意位置（或按空格）起跳。**两个小人同时跳**——一颗按钮，两条命。
- 跳过尖刺。两个世界的尖刺各自独立出没。
- **垂晶带下绝对不要跳。** 有时候最安全的操作是什么都不做——而另一个世界正逼着你跳，这种撕扯就是游戏的全部。
- 吃宝石加分。两个世界同一时刻同时出刺时，一次精准的点按可以双双跳过，触发 **SYNC +25** 奖励。
- 碰到尖刺或垂晶即死，一键秒重开。

## 为什么停不下来（设计笔记）

- **一颗按钮下的注意力分裂**：两个世界的危险时间表互相独立，大脑要不断权衡「上面现在必须跳，下面必须按住不动」。共享输入带来的张力是核心循环——借鉴的是多任务类游戏的心理学，不是任何现成玩法的换皮。
- **「禁止行动」也是一种危险**：多数跑酷只惩罚你该动不动，JINX 还惩罚你乱动——垂晶会在几秒内反转点按的意义，逼你在压力下学会克制。
- **SYNC 时刻**：偶尔对齐的双侧尖刺，把一次手忙脚乱变成一跳双过的爽点，奖励同时读两个世界的玩家，而不是乱按刷屏的人。
- **3 秒上手，30 秒一局**：只有一个动词、即死即重开；难度曲线前半分钟保持温和，之后出刺节奏收紧、世界加速（260 → 400+ px/s）。
- 内置 `localStorage` 最高分——刚才输掉的那一局，永远只差一次点按。

## 技术

单文件 HTML5 + Canvas + 原生 JS（约 320 行）。音效由 WebAudio 实时合成，无素材、无构建、支持鼠标 / 触屏 / 键盘。
