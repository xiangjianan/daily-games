# SIFTER（分拣风暴）

*红的要点碎，蓝的要吸走。一根手指，两个动词。*

一款单文件 HTML5 街机小游戏，核心是「瞬间分辨 + 选对动作」。屏幕上所有东西都在下落——红色碎片必须**轻点**捏碎，蓝色光球必须**按住**用牵引束吸进来。对错误的东西用错动词，浪费的就是你没有的那一瞬间。

▶ **在线试玩：** https://xiangjianan.github.io/daily-games/sifter-20260918// （或直接双击打开 `index.html`——零构建、零依赖、离线可玩）

## 玩法说明

- **短按**（<160ms 松开）触点附近的**红色碎片**，当场捏碎。
- **长按**打开牵引束，束内的**蓝色光球**被拉向指尖吸收；按住时可以拖动束心。
- **金色光球**三倍分——出现很少，而且专挑你手忙的时候来。
- 红色碎片碰到底线，核心碎裂，一命。死亡后一秒内点一下就能重开。
- 蓝色光球漏过底线不会死，但会**断连击**——是另一种疼。

每次成功操作连击 +1（最高 ×8），蓝球漏走清零。得分 = 基础分 × 连击。

## 为什么这样设计（沉迷机制意图）

- **3 秒上手**——标题画面就两个词：TAP / HOLD，没有教程。
- **承诺式张力**——手指按下的那一刻你就已经「选了」一个动词，160ms 之后反悔无效。按住吸蓝球时没法处理半路刷出的红片，每一次吸收都是对「下一个落什么」的小赌注。
- **不对称失败**——红片杀你、蓝球只断连击，两种死法手感完全不同，失败混合体不会腻。
- **单局一分钟内 + 秒重开**——从死亡到新开局只要一次点按，远低于一秒。
- **难度曲线**——落速 85→215 px/s、刷距 1.15s→0.58s 在约一分钟内爬满：前 30 秒是爽分局，一分钟大关才是真正的坟场。
- **合成音效**——所有声音都是 WebAudio 振荡器 + 噪声缓冲实时合成，不加载任何音频文件，离线照响。

## 操作

- 鼠标 / 触屏皆可，长按拖动都支持。竖屏布局，自适应任意屏幕。

## 技术

单 `index.html` + `game.js`，原生 JS、Canvas 2D、WebAudio。`node --check` 通过；无头 Chromium 自动化实测（零控制台报错、死亡→重开回路验证通过）。
