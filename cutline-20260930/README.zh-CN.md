# Cutline 断缆投递 · 第 22 期（2026-09-30）

单按钮物理时机街机游戏：货箱吊在横移吊臂的缆绳下摇荡，**点缆绳割断**，让货箱落进往返的接货船。落点越靠船心靶环，连击倍率越高。

**在线试玩：** https://xiangjianan.github.io/daily-games/cutline-20260930/

## 玩法

- 吊臂左右横移，货箱吊在绷直的缆绳下做真实单摆（吊臂加减速会真实甩动缆绳）。
- **点按缆绳任意位置**（或直接点货箱）割断缆绳，货箱以割断瞬间的切向速度抛出。
- 落上甲板按精度计分：**PERFECT**（靶心）/ **GREAT** / **GOOD**，连续投中叠加连击，最高 **×5 倍率**；落水扣一心，共 3 心。
- 后期出现双缆货箱——按正确顺序割，先塑形摆荡再最后一割。
- 约 45 秒起有风偏（看风向气流线），弹道会被吹歪。

## 沉迷机制设计意图

- **3 秒上手**：唯一动词就是「割」，剩下的交给物理。
- **拼预判不拼手速**：每次割断都是对约 1 秒抛物线 + 移动目标的预测，失手永远"差一点"——经典 near-miss 引擎，驱动「再来一局」。
- **混乱递增**：吊臂和船提速、甲板收窄、双缆微决策（先割哪根塑形摆荡？）、风偏弹道。
- **即时重开**：死亡 → 点一下 → 不到 1 秒开新局；最高分存 localStorage。

## 技术

单文件 HTML5 + Canvas + 原生 JS（约 390 行）。零依赖、零构建、离线可玩。WebAudio 合成音效（无音频文件）。支持鼠标与触屏。`?autotest&bot=perfect|sloppy|suicide` 内置 AI 测试机器人。
