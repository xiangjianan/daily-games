# RIPPOSTE（弹幕还击）

滑动格挡。你唯一的武器是绕着核心挥出的剑弧——接住袭来的弹幕，让它们加速 1.7 倍反杀回发射者。

## 玩法说明

- 紫色圆球敌人游走在四周，朝中央发光核心发射慢速弹幕；红色三角冲锋者会直线扑向核心。
- **滑动**（鼠标拖动或触屏划动）即可挥出一道剑弧。剑弧只在核心周围约 150px 的虚线环内生效——离核心越近，反应窗口越短，这正是张力所在。
- 弧内的敌方弹幕会被**反弹**向最近的敌人，速度 ×1.7；剑弧本身也能直接伤害碰到的敌人（射击者 2 下击破，冲锋者 1 下）。
- 核心被碰到一次即结束，点一下立即重开。
- 2 秒内连续击杀会滚出连击倍率，最高 ×5。

## 沉迷机制设计意图

借鉴爆火休闲游戏的心理钩子，逐一对应：

- **滑动即全部操作**（Fruit Ninja 血统）：一个手势零按钮，3 秒上手——但这里的剑弧首先是盾，其次才是武器。
- **格挡的双重奖赏**（弹幕 parry 类）：挡下攻击本身就是爽点，看着敌人死于自己的子弹则是头奖。1.7 倍加速 + 自动瞄准辅助把这份幻想做足。
- **短循环 + 秒重开**（Flappy Bird 血统）：单局 30-90 秒，死亡到新局不到一秒，「再来一局」的唯一成本是抬一下手指。
- **连击滚雪球**（无尽街机传统）：2 秒连击窗奖励激进的提前拦截，而不是怯懦的最后一刻格挡。
- **压力爬坡但有可读前摇**：刷怪率、弹速、冲锋者频率在两分钟内逐步上升，但每一发都有预告——射击者蓄力环、冲锋者瞄准线。死亡永远是自己手抖，不会觉得冤。

## 技术

单文件 HTML5 Canvas + 原生 JS，零依赖零联网，WebAudio 合成音效（无音频文件），localStorage 存最高分，鼠标触屏双支持。
