# SPINFALL（旋落）

点按一下，整座地牢顺时针旋转 90°。重力永远朝向屏幕下方——把它当成你的方向盘。

**[▶ 浏览器试玩](https://xiangjianan.github.io/daily-games/spinfall-20260922//)** — 无需安装、无需构建、离线可玩。克隆仓库后双击 `index.html` 即可。

## 玩法

- **点按 / 单击 / 空格**：整座地牢顺时针转 90°，小球随世界一起转，但重力只认屏幕下方。
- 沿竖井坠落、顺滚道滑行，把小球送进**绿色舱门**即可过关。
- **青色宝石**每颗 +10 分；**红色尖刺**碰上即刻终局。
- 快速过关有时间加成。关卡程序化生成、无限变难。单命单局，分数就是一切。

## 为什么会上头（设计笔记）

- **一个动词。** 全部操作就是一次点按、一个确定的效果——3 秒上手，标准超休闲公式。
- **间接操控。** 你从不直接控制小球，而是改造它所在的世界。每次旋转都有即时、可见的因果回执，明明是重力在开车，你却觉得方向盘在自己手里。
- **构造性可解。** 每一关都由「竖井 + 水平滚道」的轴对齐蛇形走廊雕刻而成——路线必然存在，所以每次死亡都怪自己的时机，不怪地图。
- **亚秒重开。** 从死亡到重来只需一次点按。单局 30–120 秒，失败成本极低，"再来一局"是本能。
- **可见成长。** 关卡数、滚动分数、时间加成，外加 `localStorage` 持久化的最高分。

## 技术

单文件 `index.html`（约 340 行）：原生 JS、Canvas 2D、WebAudio 合成音效，零依赖、零联网。支持鼠标与触屏。`?autotest` 可运行自测机器人（含引擎级单元检查）。
