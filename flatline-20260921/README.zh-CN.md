# FLATLINE（心跳节拍）

**跟上心跳，别让心电归平。** 一款考验「稳住别慌」的单指节奏街机游戏。

**在线试玩：** https://xiangjianan.github.io/daily-games/flatline-20260921// （单 HTML 文件，离线可玩）

## 玩法

- 一圈光环从屏幕边缘向中心心脏收缩。**在光环贴合心脏的一瞬间点击。**
- 你每一次成功点击都在决定你的心率——下一拍以*你实际点击的时刻*为锚点，再压缩 2.5% 并加一点随机抖动。犹豫、抢拍、慌乱，你自己的节奏就会反过来咬你。
- **PERFECT**（±75ms）双倍得分并续连击；**GOOD**（±160ms）保住命。失误 3 次，心电归平。
- 第 18 拍之后心脏开始「心律失常」：*TACHY* 突然加速、*BRADY* 突然减慢。看清横幅，立刻跟上新心率。
- 底部的心电走线实时记录你的每一拍——干净尖峰是完美发挥，杂乱毛刺就是手抖的证据。

## 沉迷设计

- **3 秒上手**——一个动作（点击），一条规则（环贴合心）。
- **节奏由你自设**——游戏从不强加节拍，它测量的是压力攀升下你的稳定性。「千万别抢拍」的紧绷感就是游戏本身。
- **BPM 爬坡**——75 → 约 187 BPM 封顶，单局 30–90 秒，死亡点一下就重开。
- **技术可见**——心电走线就是你的表现回执；连击倍率（最高 ×5）奖励稳定的心态。
- **秒级重开**——长鸣一声，一点再来。最高分本地保存。

## 操作

- 鼠标点击、触屏、空格、回车——任何能「点」的方式。

## 设计备注

原生 Canvas + WebAudio 合成（全部音效实时生成，零素材、零依赖）。难度曲线：拍间隔 800ms 每拍衰减 2.5%，±7% 抖动，下限 320ms；前 10 拍判定窗口放宽 1.5 倍，保证新手先赢一次。
