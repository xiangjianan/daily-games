# 🪃 BOOMER（回旋果园）

一指甩出回旋镖，在弧线上切开漂浮的果实，然后**接住它**——甩丢一只镖就扣一条命。单指街机，秒开秒重开，零安装。

**在线试玩：** https://xiangjianan.github.io/daily-games/boomer-20260919//

## 玩法

- 在屏幕任意处**甩动**：按下、拖动、松开。拖动矢量决定这一掷——方向定弧线，速度定远近。
- 回旋镖总会弯回你手中，**接住**才能掷下一镖。
- 切到**果实** +10 分，一次飞行连切多果最高 ×5 倍。
- 小心力度：轻甩稳稳回旋，**全力一掷会直接飞出屏幕**——那就是甩丢一只镖（−1 命）。
- 约 25 秒后，果实中开始混入**炸弹**，碰到就扣命。
- 共 3 条命，耗尽即结束——点一下立刻重开。

## 为什么停不下来

借鉴街机经典的心理钩子（水果忍者的切割爽感、Flappy Bird 的秒重开、Peggle 的「等待回旋」）：

1. **3 秒上手**——只有一个动词（甩），无需教程。
2. **天然的风险/回报旋钮**——果实越高，要甩得越狠，离「甩丢镖」越近。每一掷都是一次小赌注。
3. **回程就是免费的期待感**——每次掷出自带「它回得来吗？」的悬念，接住的瞬间音效+特效双反馈，然后立刻想再来一掷。
4. **短循环零摩擦**——单局 30–90 秒，死亡到重开只要一次点击，没有菜单。
5. **处处有 juice**——WebAudio 合成音效（无音频文件）、粒子、连切顿帧、屏震、飘分。
6. **保底公平**——果实永远刷在中等力度可达的范围内，不会出现无解局面。

## 技术

单个 `index.html`——Canvas + 原生 JS，零构建、零依赖、离线可玩。支持鼠标与触屏。最高分存 `localStorage`。

加 `?autotest` 可让机器人自动试玩（加 `&suicide` 为「只会全力甩」的自杀机器人，用于测试死亡回路）。
